LazyBuddy AI 🦥
Work less. Live more.

LazyBuddy AI is a simple, responsive productivity website built with HTML, CSS, and JavaScript for the Slow and Steady challenge.
Features
- Quick Summarizer: Creates a short extractive summary from text.
- To-Do Generator: Turns comma-separated or line-separated text into a checklist.
- Text Organizer: Sorts notes and removes duplicate lines.
- Copy Results: Copy generated results to your clipboard.
- Responsive Design: Works on desktop and mobile screens.
- Browser-based: The demo processes text in the browser and does not send it to a server.
Project Files
Keep these three files in the same folder:
LazyBuddy/
├── index.html
├── style.css
└── script.js
How to Run
1. Download or copy all three project files into one folder.
2. Make sure the filenames are exactly index.html, style.css, and script.js.
3. Open index.html in your browser (for example, Chrome).
4. Enter text in any tool and click its button.
No package installation or build step is required for this demo.
Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript
Open-Source AI Note
This version is a front-end prototype. Its summarizer, checklist generator, and text organizer use simple JavaScript text-processing rules; they do not currently call an AI model.

To make it a genuine open-weight AI project, connect the app to a local model served by a tool such as Ollama. A local model can help keep prompts on your machine, depending on how the integration is configured. Do not claim AI-powered features until the model integration has been implemented and tested.
